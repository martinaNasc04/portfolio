# Portfólio
Este é um portfólio pessoal desenvolvido em React com TailwindCSS. Nele está exibido minhas informações como desenvolvedora web, projetos, habilidades e contatos.

----
## O que foi usado:
- React: framework para desenvolver interfaces para o frontend;
- Tailwind: framework para CSS, para modificar o estilo do website;
- Motion: ferramenta para desenvolver as animações;
- Unsplash: site de imagens e ilustrações pagas e gratuitas;
- Lucide Icons: coleção de ícones;
